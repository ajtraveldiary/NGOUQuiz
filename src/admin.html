Import questions

Easiest: Download Excel, edit it, and upload it here. Rows keep their id, so they update the same questions; rows without an id are added (or update the question with exactly the same text). Questions you delete from the file are not removed: set active to no to hide one.

Columns: id, difficulty (easy / medium / hard), category, topic (optional tag), question, option_a to option_f (at least two), correct (letter A–F), explanation, active (yes / no). Excel (.xlsx) or CSV UTF-8. Malayalam text works.
